# LASER ARENA

A simple 3D multiplayer spaceship laser shooter.

## Run it on a Mac

1. Install Node.js.
2. Open Terminal.
3. Go to this folder:
   cd ~/Downloads/laser-arena
4. Install the packages:
   npm install
5. Start the game:
   npm start
6. Open this in your browser:
   
Open the address in two browser windows to test two players on the same computer.
